# Evidence Visual and Character Standard

Effective: 2026-09-30 JST. Status: mandatory current media standard.

This compatibility filename is retained because existing read gates and validators reference it.
The obsolete STATIC_TURN_FOCUS default and saturated-caption prose have been removed.

Current authority: `config/evidence_visual_static_character_policy.json`,
`config/media_user_visual_duration_preferences.json`, and `config/approved_video_template.json`.
The integrated production procedure is `docs/VIDEO_PRODUCTION_BASELINE.md`.

Use enlarged official/primary media, complete measured spoken captions, pale mint/pink
speaker colors, native speech-synchronized mouth states and authored semantic expressions.
Reuse verified narration, source media and character layers. Verify the actual final video.
Static-only rendering remains an explicit special-purpose route; it is never the normal
Zundamon/Metan explainer baseline or a substitute for requested acting.

Important retained controls: factual verification, claim/visual correspondence, source
provenance and reuse rights, voice credits, cost boundaries, meaningful pacing, mobile
safe zones, complete captions, content-addressed reuse, smallest-stage recovery,
ffprobe/decode QA and representative visual review. Unknown reuse rights block public use.
The approved internal video does not grant publication permission or certify Windows YMM4.

Detailed values and operating steps are maintained in the current machine policies and the
integrated baseline playbook rather than copied into this compatibility entry.
